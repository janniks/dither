# dither

Personal index for the agentic era. Ingest your stuff (email, calendar, browser, repos, notes), augment it with plugins, and serve it to your agents over MCP.

Local-first, plugin-driven, sandboxed. Wraps [qmd](https://github.com/tobi/qmd) for hybrid search.

```bash
npm install -g dither
dither --help
```

See [`architecture.md`](./architecture.md) for the design.
