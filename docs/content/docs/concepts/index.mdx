---
title: Concepts
description: How dither thinks about your data, your disk, and your plugins.
---

dither is local-first. Your data is plain markdown under `~/.dither/entries/`, organised into folders called collections. Plugins are Deno scripts that run in a sandbox, write markdown into a scratch dir, and have their output validated before it's promoted into your store. There's no daemon, no database for entries, no cloud — everything important is a file you can read and edit by hand.
