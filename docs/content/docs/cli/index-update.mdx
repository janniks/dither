---
title: dither index update
description: Re-scan entries and refresh the qmd index.
---

```bash
dither index update
```

Re-scans every collection (every directory under `~/.dither/entries/`) and refreshes the qmd search index at `~/.dither/qmd-index.sqlite`. Run this whenever you've edited markdown by hand, dropped in files from elsewhere, or want to make sure the index is current.

You don't need to call it after `dither plugin run` — the runner refreshes the index automatically when a plugin promotes new entries.

## Arguments and flags

None. The command takes no positional arguments and no flags in v0.

## Output

```
index updated: <N> collection(s), <N> indexed, <N> updated
```

- `collection(s)` — number of top-level subdirectories under `entries/`.
- `indexed` — entries seen and committed to the index.
- `updated` — entries whose content changed since the last pass.

When `entries/` doesn't exist or has no subdirectories, the command prints all zeros and exits successfully.

## Example

```bash
$ dither index update
index updated: 3 collection(s), 142 indexed, 7 updated
```
